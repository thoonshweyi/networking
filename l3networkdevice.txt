Hub နဲ့ Switch နှစ်ခုလုံးက Network ထဲက Device တွေကို ချိတ်ဆက်ပေးတဲ့ Networking Device တွေပါ။ ဒါပေမယ့် Data ကို ဘယ်လိုပို့သလဲ ဆိုတာက အဓိကကွာခြားချက်ပါ။

1. Hub ဘယ်လိုအလုပ်လုပ်လဲ?

ဥပမာ—

        PC A
          |
        [ HUB ]
       /   |   \
    PC B  PC C  PC D

PC A က PC C ကို Data ပို့တယ်ဆိုပါစို့။

Hub က ဘယ် Device အတွက် Data ဖြစ်တယ်ဆိုတာ မသိပါဘူး။

ဒါကြောင့် PC A က ပို့လိုက်တဲ့ Frame ကို—

PC A → HUB
        ↓
   ┌────┼────┐
   ↓    ↓    ↓
 PC B  PC C  PC D

PC B, PC C, PC D အားလုံးဆီကို ပြန်ပို့ပါတယ်။

PC C က ကိုယ့်အတွက် Data ဖြစ်လို့ လက်ခံမယ်။
PC B နဲ့ PC D ကတော့ ကိုယ့်အတွက်မဟုတ်လို့ ignore လုပ်မယ်။

Hub ရဲ့ အဓိကအချက်
Layer 1 — Physical Layer မှာ အလုပ်လုပ်တယ်
MAC Address ကို မလေ့လာ/မသိမ်းဘူး
Data ရောက်လာရင် Port အားလုံးကို ပြန်ပို့တယ်
Collision ဖြစ်နိုင်ခြေများတယ်
ယနေ့ခေတ် Network တွေမှာ မသုံးတော့သလောက်ပါ
2. Switch ဘယ်လိုအလုပ်လုပ်လဲ?

Switch ကတော့ ဘယ် Device က ဘယ် Port မှာရှိတယ်ဆိုတာ MAC Address နဲ့ မှတ်ထားပါတယ်။

        PC A
          |
       [ SWITCH ]
       /   |   \
    PC B  PC C  PC D

အစမှာ Switch က MAC Address တွေကို မသိသေးပါဘူး။

PC A က Data ပို့တဲ့အခါ—

PC A
 ↓
Switch

Switch က Frame ထဲမှာပါတဲ့ Source MAC Address ကိုကြည့်ပြီး—

MAC Address        Port
-------------------------
AA:AA:AA:AA:AA:AA    1

ဆိုပြီး MAC Address Table ထဲမှာ မှတ်ထားပါတယ်။

နောက်ပိုင်း PC A က PC C ကို ပို့တဲ့အခါ Destination MAC ကိုကြည့်ပြီး—

Destination MAC = CC:CC:CC:CC:CC:CC


Switch MAC Table
-------------------------

ဆိုတာ သိနေပြီဆိုရင်—

PC A → Switch → PC C

PC C ရှိတဲ့ Port 3 ကိုပဲ ပို့ပါတယ်။

PC B နဲ့ PC D ဆီ မပို့တော့ပါဘူး။

A → SWITCH → C

ဒါကြောင့် Switch က Hub ထက် ပို intelligent ဖြစ်တယ် လို့ အလွယ်မှတ်နိုင်ပါတယ်။

ပြီးတော့ Router ပါထည့်ပြီး Hub → Switch → Router သုံးခု ဘယ်လိုအလုပ်လုပ်ကြလဲဆိုတာ သိရင် Network အခြေခံက ပိုရှင်းသွားပါလိမ့်မယ်။

Switch  အလုပ်လုပ်ပုံကိုအသေးသစိတ်ပြောပြပါ။

ရပါတယ်။ Switch အလုပ်လုပ်ပုံကို အစကနေ အဆုံးထိ နားလည်အောင် ရှင်းပြပါမယ်။ Network အခြေခံမှာ အရေးကြီးဆုံးအချက်က Switch က MAC Address ကိုအသုံးပြုပြီး Frame ကို သင့်တော်တဲ့ Port ဆီပို့တာ ပါ။

ကိုကြည့်ပြီး Forward လုပ်ပါတယ်။

ဒါကြောင့်—

Switch → MAC Address
Router → IP Address

လို့ အခြေခံအားဖြင့် မှတ်ထားနိုင်ပါတယ်။

ဒါပေမယ့် Layer 3 Switch တွေက IP Routing လည်း လုပ်နိုင်ပါတယ်။

13. Switch နဲ့ Router တွဲသုံးပုံ

လက်တွေ့ Network မှာ ဒီလိုတွေ့ရပါတယ်။

                Internet
                    |
                 Router
                    |
                 Switch
          ┌─────────┼─────────┐
          ↓         ↓         ↓
         PC        PC       Printer
Switch ရဲ့ တာဝန်
PC → PC
PC → Printer

လို တစ်ခုတည်းသော LAN ထဲမှာ Device တွေ ဆက်သွယ်ဖို့ ဖြစ်ပါတယ်။

Router ရဲ့ တာဝန်
LAN → Internet
LAN → Another Network

လို Network တစ်ခုကနေ အခြား Network တစ်ခုကို ပို့ဖို့ ဖြစ်ပါတယ်။

15. MAC Table က အမြဲတမ်းမဟုတ်ဘူး

Switch က MAC Address တွေကို အမြဲတမ်း မမှတ်ထားပါဘူး။

MAC Table မှာ Aging Timer ရှိပါတယ်။

ဥပမာ—

MAC Address       Port     Age
--------------------------------
AA:AA...           1       20 sec
CC:CC...           3       10 sec
DD:DD...           4       5 sec

Device တစ်ခုက အချိန်ကြာကြာ Frame မပို့တော့ရင် Switch က အဲဒီ MAC Entry ကို ဖယ်ရှားနိုင်ပါတယ်။

နောက်တစ်ကြိမ် Frame ပြန်ရောက်လာရင် Switch က ပြန်လေ့လာပါတယ်။

16. Collision ကိုလည်း နားလည်ထားသင့်တယ်

Hub နဲ့ Switch ရဲ့ အရေးကြီးတဲ့ ကွာခြားချက်တစ်ခုက Collision Domain ပါ။

Hub မှာ—

PC A ──┐
PC B ──┼── HUB
PC C ──┘

Device တွေက Shared Medium တစ်ခုလို ဖြစ်တာကြောင့် Collision ဖြစ်နိုင်ခြေရှိပါတယ်။

Switch မှာတော့ Port တစ်ခုချင်းစီက သီးခြား Collision Domain ဖြစ်ပါတယ်။

PC A ── Port 1 ┐
PC B ── Port 2 ├── Switch
PC C ── Port 3 ┘

အထူးသဖြင့် ယနေ့ခေတ် Full-Duplex Ethernet မှာ Collision ပြဿနာက မရှိသလောက်ဖြစ်ပါတယ်။

အလွယ်ဆုံး မှတ်ရန်

Switch တစ်လုံးရဲ့ အလုပ်လုပ်ပုံကို ဒီ Flow တစ်ခုနဲ့ မှတ်ထားပါ—

        Ethernet Frame ရောက်လာ
                  ↓
          Source MAC ကြည့်
                  ↓
        MAC Table မှာ မှတ်
                  ↓
       Destination MAC ကြည့်
                  ↓
        ┌─────────┴─────────┐
        ↓                   ↓
     သိတယ်                မသိဘူး
        ↓                   ↓
 Correct Port             Flood
        ↓                   ↓
     Forward            Other Ports

အဓိကစကားလုံး ၅ ခု ကတော့—

MAC Address → MAC Address Table → Learning → Forwarding → Flooding

ဒီ ၅ ခုကို နားလည်သွားရင် Switch ဘယ်လိုအလုပ်လုပ်လဲဆိုတာ အခြေခံအားဖြင့် ကျွမ်းကျင်သွားပါပြီ။

Switch ရဲ့ အဓိက Process 3 ခု  

Switch ရဲ့ အဓိက Process 3 ခု ကို အလွယ်ဆုံးနဲ့ အသေးစိတ်ပြောရရင်—

1. Learning — MAC Address ကို မှတ်ခြင်း

Switch က Frame ဝင်လာတိုင်း Source MAC Address ကိုကြည့်ပါတယ်။

ဥပမာ PC A က Port 1 ကနေ Frame ပို့လာတယ်—

PC A
MAC = AA:AA:AA:AA:AA:AA
        ↓
     Port 1
        ↓
     Switch

Switch က—

AA:AA:AA:AA:AA:AA → Port 1

ဆိုပြီး MAC Address Table ထဲမှာ မှတ်ထားပါတယ်။

ဒါကို MAC Address Learning လို့ခေါ်ပါတယ်။

2. Forwarding — သင့်တော်တဲ့ Port ကို ပို့ခြင်း

Switch က Frame ရဲ့ Destination MAC Address ကိုကြည့်ပါတယ်။

ဥပမာ—

Destination MAC
= CC:CC:CC:CC:CC:CC

MAC Table ထဲမှာ—

MAC Address              Port
--------------------------------
AA:AA:AA:AA:AA:AA        1
CC:CC:CC:CC:CC:CC        3

လို့ရှိရင် Switch က သိပါတယ်—

CC:CC... က Port 3 မှာရှိတယ်။

ဒါကြောင့်—

PC A
  ↓
Port 1
  ↓
Switch
  ↓
Port 3
  ↓
PC C

Port 3 ကိုပဲ ပို့ပါတယ်။

ဒါကို Forwarding လို့ခေါ်ပါတယ်။

3. Flooding — မသိရင် အခြား Port တွေဆီ ပို့ခြင်း

Destination MAC ကို Switch က မသိသေးရင် ဘယ် Port ကိုပို့ရမလဲ မသိပါဘူး။

ဥပမာ—

Destination MAC
= DD:DD:DD:DD:DD:DD

ဒါပေမယ့် Table ထဲမှာ—

AA:AA... → Port 1
CC:CC... → Port 3

ပဲရှိတယ်။

DD:DD... မရှိသေးဘူး။

ဒါဆို Switch က—

             ┌── Port 2 → PC B
             │
PC A → Switch ├── Port 3 → PC C
             │
             └── Port 4 → PC D

လို ဝင်လာတဲ့ Port မဟုတ်တဲ့ အခြား Port တွေဆီ ပို့ပါတယ်။

ဒါကို Flooding လို့ခေါ်ပါတယ်။
