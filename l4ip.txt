Subnet Mask ဆိုတာဘာလဲ?

Subnet Mask က

IP Address ထဲမှာ ဘယ်အပိုင်းက Network ဖြစ်ပြီး ဘယ်အပိုင်းက Host ဖြစ်လဲဆိုတာ သတ်မှတ်ပေးတာ

ဖြစ်ပါတယ်။

ဥပမာ—

IP Address : 192.168.1.10
Subnet Mask: 255.255.255.0

Binary နဲ့ကြည့်ရင်—

IP:
11000000.10101000.00000001.00001010

Mask:
11111111.11111111.11111111.00000000

1 တွေက Network Part

0 တွေက Host Part ဖြစ်ပါတယ်။

11111111.11111111.11111111 | 00000000
          Network           |   Host

192.168.1.10/24
